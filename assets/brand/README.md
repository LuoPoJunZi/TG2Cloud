# TG2Cloud v1.0.0 品牌资源

本资源包基于最终选定的 TG2Cloud Logo 制作，目录可直接复制到 TG2Cloud 项目根目录。

## 文件结构

```text
assets/brand/
├── tg2cloud-logo.svg
├── tg2cloud-icon.svg
├── tg2cloud-icon.png
├── tg2cloud-icon-32.png
├── tg2cloud-icon-64.png
├── tg2cloud-icon-128.png
├── tg2cloud-icon-256.png
├── tg2cloud-icon-512.png
├── tg2cloud.ico
├── tg2cloud-logo-preview.png
└── README.md
```

## 推荐用途

- `tg2cloud-logo.svg`：README、官网、About、文档横版 Logo。
- `tg2cloud-logo-preview.png`：最终 Logo 的原始透明 PNG 预览。
- `tg2cloud-icon.svg`：UI 中可缩放的图标资源。
- `tg2cloud-icon.png` / `tg2cloud-icon-512.png`：PySide6 主图标、高分辨率场景。
- `tg2cloud-icon-32.png` / `64.png`：小尺寸 UI、网页图标。
- `tg2cloud-icon-128.png` / `256.png`：应用界面、发布页、快捷方式。
- `tg2cloud.ico`：Windows EXE / PyInstaller 图标。

## 品牌名称

正式名称统一使用：`TG2Cloud`

两个版本建议显示为：

- `TG2Cloud · CloudDrive2`
- `TG2Cloud · OpenList`

## 说明

本包中的 SVG 为自包含 SVG：内部嵌入最终选定的 PNG 图形，以保证和确认的 Logo 视觉一致，不依赖外部图片文件。后续如果需要完全可编辑的纯路径矢量版，可再单独重绘。
