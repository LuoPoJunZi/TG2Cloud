## WARNING 的含义

本次出现四类提示，没有阻止镜像构建、Bot 启动或最终检查。它们不是同一类风险，不能推广为“任何 WARNING 都可以忽略”。

| 提示 | 本次解释 |
| --- | --- |
| `Running pip as the 'root' user` | 出现在 Docker 镜像构建的依赖安装步骤，不是在宿主 Python 环境安装 Bot 依赖。项目镜像和 Compose 配置运行用户为 `10001:10001`，不是让 Bot 长期以 root 运行；本日志未单独执行运行用户查询 |
| `skipping ca-certificates.crt` | rehash 对包含多张证书的 CA 合集文件不建立单证书索引，不等于域名证书失效；证书包安装结束，本机 HTTPS 后续检查通过 |
| `uid 10001 is greater than SYS_UID_MAX 999` | 容器账号固定 UID 超出系统账号默认编号范围的提醒；账号创建步骤成功，未发生 UID 被改成 root 或权限提升 |
| 安装文件系统总容量低于推荐 50GB | 推荐容量提醒，而非硬性 50GB 安装门槛；本次容量检查通过，但后续仍须遵守暂存预算、真实可用空间和网关缓存保护 |

通用判断方法、官方说明和需要停止的情形见[安装与升级 FAQ](../FAQ.md)。不需要为消除这些文字改成 root 运行 Bot、放宽目录权限、删证书或绕过检查。
