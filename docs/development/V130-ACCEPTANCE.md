# v1.3.0 CloudDrive2 升级验收

记录日期：2026-10-17。对象为专用 Debian 13 x86_64 测试 VPS 上的 CloudDrive2 Edition；宿主 Python 3.13，Bot 容器 Python 3.12。正式源码来自 [v1.3.0 Release](https://github.com/LuoPoJunZi/TG2Cloud/releases/tag/v1.3.0)，对应提交 `27874c12c6166e12f2f57759199576cffb9f3234`。

## 迁移方式与安全边界

原实例是版本标为 v1.2.0 的旧测试候选，不是与官方 v1.2.0 逐文件相同的标准实例。在线 `--check` 正确拒绝自动覆盖；本次经用户授权，人工核对、备份后调用正式版的原生安装与回退流程迁移到 v1.3.0。没有修改版本号冒充官方基线，没有放宽产品检查，也不提供强制覆盖参数。

因此，本记录证明这次有备份的人工迁移成功，不代表任意旧候选、自定义代码或同号实验版本都能由一键脚本自动升级。遇到源码不一致时，应保留实例和备份，单独核对迁移；不要删数据库、Session 或版本记录绕过检查。

rclone 启动时会重新混淆保存的 WebDAV 密码，`rclone.conf` 字节可因此变化。此次最初的逐字节附加检查报错后，保留该记录并进行语义核对：密码解混淆后相同，其他配置值也相同，未改密或盲目重装。混淆不是加密；配置和备份仍按凭据文件私密保存。

## 不扩展本次结论

- OpenList 脚本实机验收暂缓；其旧版或隔离测试结果不能代替本次 v1.3.0 实机升级。
- 全新 VPS 安装、正式旧版之间无需人工接管的自动升级、回退故障注入、长期续期与完整灾难恢复未在本次执行。
- 内网/NAS 升级、ARM64、双 Edition 同时升级，以及不同文件规模、流式中断、取消恢复和媒体组命名的全部实机场景仍需独立验证。
- 当时下载目录为空，不能据此宣称带保留缓存任务的升级恢复已实测。
- 网关保持运行；其 SQLite 使用在线备份，其他网关文件仅为运行中副本，未遍历云盘/FUSE 挂载。此实例备份不含共享 HTTPS，也不等于离线整机快照或已通过服务恢复演练。
- WebDAV 大小校验不等于内容哈希校验，也不代表云存储官方后台已完成。重要文件仍需在官方客户端核对。
