# TG2Cloud 品牌资源使用

正式名称固定为 **TG2Cloud**，标语为 **From Telegram to Your Cloud**。CloudDrive2 Edition 与 OpenList Edition 使用同一主品牌；115 只是可选后端，不把项目品牌改成单一网盘工具。

## 唯一资源来源

`assets/brand/` 是唯一正式来源，当前实际提供：

| 文件 | 使用场景 |
| --- | --- |
| `tg2cloud-logo.svg` | README、项目介绍和网站横版 Logo |
| `tg2cloud-logo-preview.png` | 正式 Logo 预览 |
| `tg2cloud-icon.svg`、`tg2cloud-icon.png` | 图标原始资源 |
| `tg2cloud-icon-32.png`、`64.png` | 网页与小尺寸界面图标 |
| `tg2cloud-icon-128.png`、`256.png`、`512.png` | 发布页或高分辨率展示 |
| `tg2cloud.ico` | 网站 favicon 的来源之一 |

SVG 包含已确认的嵌入图形，不宣称它是可任意重绘的纯路径图。参见[资源说明](../../assets/brand/README.md)。

## 网站与项目首页

README 使用 `assets/brand/tg2cloud-logo.svg`；网站 `public/` 中的副本必须与对应正式资源逐字节一致。现有测试核对摘要，不修改 Logo、配色、图标或作者头像来配合文档整理。

两个 Edition 的名称可显示为 `TG2Cloud · CloudDrive2`、`TG2Cloud · OpenList`。目录、容器和数据库兼容名称不是品牌资源，不为视觉统一批量替换或删除。

## 调整与验收

只缩放已有资源，不覆盖原件。确需派生尺寸时先核对实际文件，另存新文件并记录来源及处理方式，不用截图或重绘图冒充正式 Logo。检查浅色／深色背景可读性、长宽比、favicon 与移动端显示。

上游 TG115 的项目名称、原作者和 MIT 版权保留在许可证与致谢中。不得为了新品牌移除来源说明，不把第三方服务标志描述为官方合作关系。
