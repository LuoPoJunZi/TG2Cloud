# v1.3.3 CloudDrive2 升级与转存验收

记录日期：2026-10-19。只记录已经执行或由用户明确确认的范围，不公开主机地址、账号、真实文件名、配置或私密备份位置。

## 对象与授权边界

用户指定的专用测试 VPS，先验收 **CloudDrive2**；从正式 v1.3.2 升级到正式 v1.3.3。保留已有配置、任务数据库、Telegram Session、域名和网关数据；不卸载，不降级，不升级 OpenList，也不升级独立外部 WebDAV。

这次是标准正式版之间的保留配置升级，不是此前将未发布候选人工迁入 v1.3.0 的路径。历史情况另见 [v1.3.0 记录](V130-ACCEPTANCE.md)。

## 不属于本次通过范围

- 全新 VPS 安装、NAS／LAN、ARM64、OpenList 升级或双 Edition 同时升级。
- 两位真实用户的任务权限隔离、外部 WebDAV 家人账号与手机播放／拖动。
- 真实远端冲突、上传中断、取消删除、数据库恢复、候选失败回退或灾难恢复。
- 长期自动续期、完整卸载／数据清理。
- v1.3.3 之后的本地命名边界修复；它们尚未发布、未部署。
- 云盘官方最终入库、内容哈希一致或所有文件类型的实际命名准确性。

先前自动 CI、隔离 WebDAV 和离线合成命名测试是不同证据，不混写成此 VPS 上的真实网盘测试。

## 下一次回归建议

按[升级指南](../VPS-INSTALL.md#已有实例升级)先预检、备份、再确认，升级后核对真实版本与历史配置，最后由用户转存自有测试文件。命名的新回归样本见[命名指南](../NAMING.md#如何验收和反馈)，家庭和外部访问按各自清单独立执行。

发生失败时保留配置／DB／Session 和现有私密备份，不通过卸载、改版本号或放宽指纹校验进行重试。需要故障回退或生产恢复，应另行明确授权并先在隔离环境验证。
