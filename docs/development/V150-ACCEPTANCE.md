# v1.5.0 发布与管理工具验收

## 当前状态

2026-10-27：用户授权提交推送并正式发布 v1.5.0。当前为发布准备；本地修改、辅助提交 A、入口提交 B、远端 CI、同标签发布与实际资产分别记录，不用前一个版本的结果替代本版。

## 变更与兼容

- Bot 与宿主 CLI 分别验收，管理工具来自目标正式 Release 的已核验源码；静态版本、安装清单、`--version` 和 `listen --help` 必须对应。
- 在线向导监听登录兼容当前控制终端；手机号和验证码可见，2FA 隐藏，不记录凭据。无终端或实例不匹配时停止。
- 同批次媒体组预览与实际筛选共用文字关联；来源修订变化使旧轮询失效，下载前重查账号／连接／附件。
- 无新增 DDL、依赖、必填配置、端口；保留 schema 3、任务、Session、安装目录和两个 Edition 的后端差异。
- 首页及导航统称 Linux。技术检测和 CI 继续分别验证两个受支持的原生平台，不扩大系统支持承诺。
- 历史 v1.4.11 基础升级反馈见[原记录](V1411-ACCEPTANCE.md)，不是 v1.5.0 实机验收。

## 发布门槛

1. 辅助代码 A 使用真实公开 SHA，先完成五项 CI。
2. 两个入口 B 只固定已验证 A；保留正式 Release 校验，不改为 main 业务代码。
3. B 的 CI 全部成功后创建不可变 v1.5.0 Tag，同标签工作流校验 Linux 和两个 Edition，再发布一次源码包与 SHA256。
4. 实际下载资产，运行正式验证器，逐文件核对 Tag，并检查两个公开安装入口及 helper 文件。
5. 发布后更新 README、网站状态和发布证据；不改写旧 Tag 或已发布资产。

## 发布后安装与验收

先通过菜单 13 备份配置和一致性数据库快照，私密保存个人 Session，避免两个实例共用同一 Bot Token。同时保留原版本、程序／镜像身份、网关和 HTTPS 备份。

正式发布后运行：

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/LuoPoJunZi/TG2Cloud/v1.5.0/install.sh) --edition clouddrive2 --release v1.5.0 --check
bash <(curl -fsSL https://raw.githubusercontent.com/LuoPoJunZi/TG2Cloud/v1.5.0/install.sh) --edition clouddrive2 --release v1.5.0
```

OpenList 改为 `--edition openlist`；内网使用同标签 `install-lan.sh`，保持原模式。以下项目均待用户在独立测试环境验收：

| 项目 | 操作与预期 | 失败时处理 |
| --- | --- | --- |
| 版本同步 | 从 v1.4.11 升级，摘要中 Bot 和 CLI 均为 1.5.0；退出旧菜单，`tg2cloud --version` 相同 | 保留实例和备份，收集脱敏版本及停止阶段；不要卸载 |
| 离线命令 | 断开 GitHub 后，版本查询及 `listen --help` 仍可运行 | 不重置 Session 或重新创建数据库 |

## 本地验证

发布版本同步后的结果将在实际运行后追加。Linux 容器、真实 Telegram、网关、ACME、手机及故障恢复不以模拟测试替代。

### 版本同步后的本地结果

完整检查 1356 项：1322 通过、34 个既有环境条件跳过、0 失败；Ruff、compileall、公共文件及文档索引通过。网站构建和 37 项测试通过，34 HTML／4337 本地引用／290 搜索项；Bash 两入口及原有 ShellCheck 范围、Bandit 通过。首次网站检查仅因待发布版本缺少既定的加粗／状态标记失败，修正文案后通过，未改测试或规则。

本机为 Windows；跳过项来自 Linux UID／权限／flock／PTY、缺少 rclone 和未启用隔离 Docker。待远端原生 Linux 两平台与两 Edition 验证，不能将本地跳过记为通过。本轮没有新增运行依赖或恢复 EXE。

### 切换期间旧正式版兼容

新入口与正式资产发布存在先后顺序：目标仍为旧稳定版时，管理工具继续来自该已校验 Release。仅对已知旧版本和 argparse 明确“未提供命令”的退出结果标记 legacy，并显示未验证／不提供项；v1.5.0 缺少版本查询或任意未知错误仍失败。不会为了发布切换而回退到 main、降低文件身份检查或把缺少的命令记为通过。
