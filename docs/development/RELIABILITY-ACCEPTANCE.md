## 发布门槛与暂缓项

自动测试通过仍需上述真实验收。不自动执行远端部署、删除云文件、推送或发布。当前未增加通用哈希/远端回读、生产一键 Restore、网关独立文件系统自动采集、CloudDrive2 降权或完整新架构；这些需要单独设计与授权。

按用户确认的维护版本 **v1.2.1** 准备发布，实际产物由 GitHub Actions 生成；真实转存等未完成项目继续明确保留。更新摘要：

- 支持已取消任务经确认重新转存，保持去重与历史记录。
- 上传结果不确定时保留原文件，允许确认后换名重传。
- 遗留扫描增量读取并明确完整性，删除保护不变。
- 记录大小验证方法/时间，增强 DB 回退与离线恢复预检。
- 增强多文件系统空间诊断、错误脱敏和任务查询。

发布前再次核对 changelog 与真实测试记录，正式 EXE 仍由 Actions 构建一次并复用该 artifact；不得上传本地测试 EXE 或重写历史版本。
