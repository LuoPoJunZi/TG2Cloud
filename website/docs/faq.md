# 常见问题 FAQ

按问题所属阶段排查，避免用一个“修复”按钮处理所有错误。

## 项目与使用

### 只能转存到 115 吗？

不是。目标取决于你在 CloudDrive2 或 OpenList 中挂载并授权的存储。115 是主要测试场景之一；其他存储是否可用，应做真实 WebDAV 和文件测试。

### 可以自动监听频道吗？

当前不可以。你手动选择文件并转发给自己的私人 Bot，VPS 自动处理之后的步骤。它不自动爬取频道，也不批量读取频道历史。

### 必须开 Telegram Premium 吗？

项目准备清单没有把 Premium 列为必需项。但可获取文件、平台限制和实际速率仍受环境影响。不能因此承诺任何会员权益或固定速度。

### 2GB 文件一定几分钟上传完吗？

不能保证。看 Telegram 下载、VPS 网络、WebDAV、网关和云存储的实际瓶颈。[速度说明](/usage/streaming/) 给出了带单位的理论计算，不是实测成绩。

## 安装与登录

### Windows 提示未知发布者怎么办？

v1.1.2 未提供商业代码签名。核对正式 Release、文件名和 SHA-256，不要直接关闭全局安全防护。[下载与校验](/download/)。

### VPS 重装后 Host key 不匹配？

先在服务商控制台核对新指纹，确认身份后使用部署器“更新并重新连接”。不要删除所有服务器记录。[SSH 排查](/troubleshooting/ssh/)。

### 找不到 OpenList 首次管理员密码？

已有实例部署后，首次初始化密码不再适用，应使用原管理员凭据；不要把新的本地表单值当成服务端已重置的密码。[OpenList 教程](/deploy/openlist/)。

### CloudDrive2 提示没有 FUSE？

同机受管 CloudDrive2 需要 `/dev/fuse`。请确认 VPS 虚拟化和服务商支持，而不是反复更改 WebDAV 密码。

## 管理页与 WebDAV

### HTTPS 管理页打不开？

在部署器的“HTTPS 管理入口”中点击“检查状态”，核对 DNS、证书、80/443、Nginx、HTTP 跳转和后端回环监听。首次签发时 Cloudflare 使用“仅 DNS”；CloudDrive2 19798 与 OpenList 5244 不应直接暴露公网。

### HTTPS 能用，为什么显示黄色续期警告？

最近续期失败、已有记录超过 26 小时未更新、临近到期或时钟异常都可能触发提醒；当前严格 HTTPS 自检通过时，入口仍可用。检查续期记录、VPS 时间和 Certbot，不必因此重装 Bot。完全没有记录的旧实例只显示“尚无记录”，需用新版部署器重新配置同一域名更新记录能力。[HTTPS 维护说明](/deploy/domain-https/)。

### 填了 Let's Encrypt 邮箱就会收到到期提醒吗？

不会。其到期提醒邮件服务已停止，填写邮箱不能替代续期监测。续期检查成功也可能表示证书无需更新，不能当作已续签。

### 401 与 429 有什么不同？

401 优先检查运行配置中的 WebDAV 用户名、密码；429 属于限流，避免连续重试加重压力。两者不能用同一种方案处理。[WebDAV 排查](/troubleshooting/webdav/)。

v1.1.2 的 OpenList Bot `/doctor` 会显示实际探测时间与剩余冷却；刷新诊断不会绕过退避，也不会把消息刷新时间冒充新探测结果。

### 修改部署器密码后还是 401？

表单变更不等于 VPS 配置变更。重复部署默认保留原 `.env`，单纯 restart 也不应用新配置。按 [修改配置](/operations/update/) 明确应用后再验收。

### “修复 CloudDrive2 网络”能解决上传失败吗？

只针对适用的容器网络问题，不能修复错误密码、只读权限、未挂载云盘或配额不足。

### MOVE 返回成功就通过了吗？

不能这样判断。v1.0.2 对 OpenList 改为直接写入预留最终路径；CloudDrive2 仍使用临时文件改名后复验。必须看最终验收结果。

## 任务与数据

### Bot 一直排队？

先看 `/status` 顶部运行状态和排队数量；需要检查 CPU、内存、磁盘与本地额度时，点击首页的 `🖥`。调度暂停状态可用 `/status` 顶部提示和 `/doctor` 进一步确认。[传输排查](/troubleshooting/transfer/)。

### 为什么暂停后还有传输？

`/pause` 只暂停新任务调度，不打断活动任务。暂停状态跨重启保存，恢复用 `/resume`。

### Bot 完成是否代表云盘官方完成？

不代表。Bot 校验 WebDAV 接收与文件大小，不接入云盘官方完成接口；重要文件需在官方客户端检查内容。

### 流式模式是不是完全不占磁盘？

不是。它不留完整本地副本，但网关缓存、日志、Docker 和备份仍占用磁盘。

## 升级与迁移

### 下载 v1.1.2 EXE 后，Bot 还是旧版？

下载只更新你电脑上的部署器，不会自动安装 VPS payload。通过“查看运行状态”核对实际 Bot 版本，再使用新版部署器保留配置重新部署；未获取版本不代表已更新，较新版本也不会被自动降级。[升级说明](/operations/update/)。

### `manage.sh update` 会下载 GitHub 最新源码吗？

不会。它主要用已安装 payload 重建；安装新版应使用新版部署器，详见 [升级](/operations/update/)。

### TG115 能一键升级 TG2Cloud 吗？

v1.1.2 不提供原地自动迁移，也没有正式自动 Restore/Uninstall。[迁移说明](/operations/migration/)。

### CloudDrive2 现在能备份了吗？

两版都有“HTTPS 管理入口 → 维护工具”的共享代理备份，但不包含 Bot 业务数据或网关状态。CloudDrive2 仍没有手动业务安全备份 UI；OpenList 日常管理的业务备份与代理备份也须分别保存。[备份范围](/operations/backup/)。

### CloudDrive2 和 OpenList 可以共用一个 Bot Token 吗？

不要让两版或新旧实例长期同时使用同一个 Token，否则可能争抢 updates。没有分布式锁替你自动防止这种冲突。
