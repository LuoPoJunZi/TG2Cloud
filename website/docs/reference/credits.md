# 项目来源与致谢

TG2Cloud 建立在开源项目的持续改进之上。保留原作者、上游版权与许可证，是项目文档的一部分。

## 原始项目

感谢 [whyhhh20/TG115](https://github.com/whyhhh20/TG115) 提供的原始项目基础。

TG2Cloud 是在该基础上的二次开发版本，继续保留 MIT 许可证和必要版权声明。原项目与当前 TG2Cloud 的功能边界、版本号及部署方式并不完全相同。

## TG2Cloud 维护仓库

当前仓库为 [LuoPoJunZi/TG2Cloud](https://github.com/LuoPoJunZi/TG2Cloud)，主打私人 Telegram Bot、自托管 VPS、双存储网关和可验证的 WebDAV 转存流程。

感谢帮助发现部署、网络、WebDAV 和界面问题的用户，以及相关开源工具的维护者。

## 相关组件

Telegram、Docker、rclone、PySide6 和 OpenList 等组件提供了通信、运行、传输和界面能力；CloudDrive2 提供另一种存储网关选择。

各组件与云存储服务有自己的许可证、使用条款和信任边界，应分别遵守。TG2Cloud 的 MIT 许可证并不替代第三方服务条款。

## 无官方隶属关系

TG2Cloud 与 Telegram、115、CloudDrive2、OpenList 及其运营方没有由本文档声称的官方合作、授权或隶属关系。名称仅用于解释互操作方式。

## 本文档站

本网站参考 TG115 文档站的阅读结构，重新整理为面向 TG2Cloud 双 Edition 的中文文档。使用轻量静态实现，源码与内容可独立维护。

顶部标识是本站的轻量文字与界面符号，不声称是从部署器提取的原始品牌图片。文档内容依来源整理，详见 [来源说明](/reference/sources/)。
