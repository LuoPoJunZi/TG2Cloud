# Compose 管理与安全维护

本页适用于 **v1.5.8 format 3 完整部署包**。先核对[发布状态](https://github.com/LuoPoJunZi/TG2Cloud/blob/main/docs/development/V158-ACCEPTANCE.md)及资源，旧 v1.5.7 包没有 manage.sh，不只复制单个脚本。安装步骤见 [Compose 教程](/deploy/compose/)。

## 随包离线菜单

本版完整 format 3 部署包包含 `manage.sh`，使用同包 `https-tools/` 中经过清单核验的 Python 代码。在实际部署目录运行：

```bash
bash manage.sh
```

宿主需要 Linux、Python 3.10+、Bash、本机 Docker Compose 及 root 权限，帮助和维护不要求安装 Bot 依赖，不每次下载 main。也可从其他工作目录按绝对路径调用。不会默认覆盖脚本实例已有的全局 `tg2cloud` 命令。

菜单复用现有状态、日志、服务启停、家人授权、WebDAV 凭据、HTTPS、分类、通知、就绪检查、写入验收、诊断、监听和外部只读 WebDAV。另提供 Compose 专用升级、备份、卸载和资源设置。

两 Edition 仍分别管理容器、网络、数据库、配置与 Session，不接管脚本安装实例。Docker 与系统依赖仍由用户准备，不调用主安装器重新部署。未知容器、链接目录、额外 override、被修改的基础 Compose 和不匹配挂载会停止自动管理。

## 凭据和资源

新版 Bot 明确接收所需配置，不再加载整份 `.env`。OpenList 初始管理员密码只给网关，不交给 Bot。现有旧容器要经完整新版包重建后才生效。主机 `.env` 仍须保护为 root 所有、600 权限，Base64 不等于加密。

Bot 默认进程／线程上限 256，内存和 CPU 硬限制默认不设置。“资源与安全”允许设置 Bot 内存、CPU 和进程上限；须先暂停新任务并等活动传输结束，确认后仅重建当前 Bot，再读取 Docker 实际限制核验。旧配置保留为本机私密备份。

CloudDrive2 的 FUSE 和原有必要高权限保留，它依然是高信任组件；本次没有移除这些能力。OpenList 的非 root 与权限限制、Bot 非 root、回环端口和日志轮转继续保留。Bot 限额不限制网关全部缓存，不要为消除排队降低保护门槛。

## 排队不下载如何判断

新业务就绪观察加入有效可用内存、下载门槛、容器内存上限、下载／上传窗口和等待原因。标准 Docker cgroup v1／v2 的内存余量会参与采样，低于门槛不再把下载资源标记为通过。

诊断按固定类别汇总排队任务的重试等待、个人并发、暂存额度、真实磁盘等待，不输出原始文件名和凭据。复杂 NAS／嵌套 cgroup 仍要核对实际容器限制。旧版本没有这些字段时显示“未核实”；容器 healthy 仍不等于已经能下载或上传。

## 升级与备份

升级只使用正式稳定 Release 的同版 Compose 资产、校验清单、镜像 digest 和真实提交；失败不回退执行 main。先停止当前 Bot 并创建一致性快照，保留 `.env`、数据库、Bot／个人 Session、下载与网关数据，再切换本 Edition。调度暂停状态保留，用户完成业务验收后自行恢复。

菜单自动升级要求旧包已有完整 `https-tools/`（format 2）。更早的 format 1 没有离线工具，程序会明确停止；须先完整备份，按原 Compose 教程核对部署文件并保留数据，不能仅复制新脚本或伪造标记。

新 Bot 启动前失败时尝试恢复旧部署与服务；新 Bot 可能写入数据库后失败，会停止它并保留现场与事务记录，不自动覆盖旧库或启动旧代码。备份、匹配版本和隔离预检见 [备份恢复](/operations/backup/)。

实例备份包含私密配置与授权，不包含云端文件、下载、日志或共享代理。菜单另提供代理备份，以及宿主已装 GnuPG 时的 AES256 加密副本：口令隐藏输入，只通过 stdin 交给 GnuPG；先解密回读，再发布加密副本，原明文归档保留。用户另存口令和加密离机副本。结构预检不等于服务恢复成功，不提供自动覆盖生产库的一键恢复。

## HTTPS、外部读取与卸载

受管 Nginx＋Certbot 与外部只读 WebDAV 复用公共功能，外部账号仍需独立只读权限和目录隔离，网关保持回环绑定。已有第三方代理仍提供候选配置导出；暂不自动接管外部代理 schema 3，也不在该模式安装 Compose 外部 WebDAV。

卸载只清理核验过的本 Edition 服务、自有且无其他连接的网络。删除实例数据须再次确认，并先检查所有清理范围；遇到链接、挂载、特殊文件或非空 CloudDrive2 挂载点即停止。保留另一 Edition、云端文件、系统 Docker／Nginx、独立导出备份，以及公开部署包、操作记录和锁文件。有外部 WebDAV 依赖时须先从其菜单卸载。

## 发布前与实机验证

本版按 helper A／入口 B、远端 CI、同 Tag 共享镜像及两份 format 3 包统一发布；实际结果见发布记录。真实 Telegram、两网关转存、ACME、外部读取、升级与卸载在发布后由用户验收，离线模拟不能代替这些结果。
